# Security policy

AgentEvidence is experimental research software. It has not undergone an independent security audit. Do not treat its trace audits, checksum comparisons or supplied JUnit reports as security attestations. Do not feed it secrets or execute untrusted test suites as part of evaluation.

If you believe you found a sensitive vulnerability, do not share exploit material or secrets in a public issue. Use private vulnerability reporting when available and await maintainer guidance. Ordinary non-sensitive correctness bugs may be reported in a public issue after the project is published.

The tool itself does not execute commands from a trace and does not attempt to authenticate external artifacts.
